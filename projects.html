MyGTAP Modelling Framework

The MyGTAP framework is an enhanced version of the Standard GTAP model that allows users to further disaggregate households and factors (endowments) of production and incorporate foreign income flows and transfers. The MyGTAP model is programmed in GEMPACK and is provided with all the files required to integrate the model code into RunGTAP. All features of RunGTAP including altertax, GTAPView, volume changes and welfare decomposition are supported.

ImpactECON Supply Chain framework

The ImpactECON Global Supply Chain package is a set of data and programs that allow the user to convert the GTAP Data Base into a global supply chain database for CGE modeling. The package was developed as a means of improving analysis of the impact of trade and environmental policies on the global economy, trade, production and employment.
